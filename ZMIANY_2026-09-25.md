## Pkt 4 — widok Przewagi

### `src/Advantages.tsx`, funkcja `assumptionFigure` (zastępuje `assumptionText`)

Założenie jest pokazane jako duża liczba z etykietą „Założenie” i podpisem z danych, np. `10–25 %` · „Odzysk przychodu z rozliczenia renderów”. Jednostki są brane z pola `unit`. Poprzednia wersja wpisywała „h / artystę / mies.” każdemu założeniu poza A-ODZYSK.

```tsx
function assumptionFigure(data: FeaturesData, advantage: Advantage, lang: LangKey) {
  const a = data.assumptions.find((item) => item.id === advantage.assumptionId);
  if (!a) return null;
  const range = a.maxValue !== undefined ? `${a.value}–${a.maxValue}` : `${a.value}`;
  if (a.unit === "%") return { value: `${range} %`, unit: "", caption: a[lang] };
  return { value: `${range} ${a.unit.split(" / ")[0]}`, unit: UNIT[a.unit]?.[lang] ?? a.unit, caption: a[lang] };
}
```

## Pkt 6 — telefon

### `src/App.tsx`, stała `NARROW` i inicjalizacja `view`

Na ekranie do 720 px bez parametru `?view=` strona startuje od **Przewag**, bo chmura jest tam nieczytelna. Zakładka Chmura dalej działa, a na komputerze nic się nie zmienia.

```tsx
const NARROW = typeof matchMedia === "function" && matchMedia("(max-width: 720px)").matches;
return value === "advantages" || value === "grid" || value === "cloud" ? value : NARROW ? "advantages" : "cloud";
```

## Pkt 7 — porządek w `src/styles.css`

Z części sprzed dzisiejszych zmian usunąłem **350 deklaracji**, które w całości nadpisywały późniejsze reguły albo dotyczyły klas nieużywanych w kodzie (`.graph-guide`, `.edge-key`, `.stage-row`, `.swatch`, `.is-cross`). Ta część zmalała z 1267 do 1088 linii.

Jak to sprawdziłem:

1. Skrypt w przeglądarce testował każdą deklarację w 104 stanach strony: 3 widoki, karta, dymek, wyszukiwarka, spacer, podświetlona przewaga, 2 motywy i 4 szerokości (1440, 1100, 760, 390). Deklaracja trafiała na listę do usunięcia tylko wtedy, gdy jej brak nie zmieniał wyliczonego stylu żadnego elementu.
2. Drugi przebieg wykrył pary deklaracji, które dublowały się nawzajem. Z każdej takiej pary jedna została.
3. Porównałem zrzuty przed i po piksel w piksel. Widoki Przewagi i Etapy pracy są identyczne. W chmurze różnice to pojedyncze piksele antyaliasingu, takie same jak między dwoma przebiegami na niezmienionym CSS.

Reguły z `:hover`, `:focus` i animacjami nie były ruszane.

Nowe style są w jednym bloku na końcu pliku, pod nagłówkiem `2026-09-25 · Czytelność prezentacji danych`.
